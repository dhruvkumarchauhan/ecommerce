# NOVA — Responsive React E-commerce Store

A polished, responsive storefront built with React. The project includes a responsive navigation bar, product search, category filters, sorting, product cards, wishlist toggles, a working demo shopping bag, and a newsletter interaction.

## Run locally

1. Open this folder in VS Code.
2. Open the terminal in the project folder.
3. Run `npm install` (only if dependencies are not already installed).
4. Run `npm start`.
5. Open `http://localhost:3000`.

## Notes

- Product data is currently stored in `src/App.js` for easy editing.
- Cart and wishlist state are demo-only and reset when the page reloads.
- Checkout and newsletter submission are front-end demonstrations; no payment or email service is connected.
- Product photography is loaded from Unsplash and requires an internet connection.
